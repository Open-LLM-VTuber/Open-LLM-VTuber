# 直播模式

启动：`VTUBER_LIVE_MODE=1 uv run run_server.py`。模式在进程启动时确定，切换必须重启。默认私人模式，避免未经检查即公开播出。

历史记录保存在 live_history，跨会话检索同样只访问直播历史。原有 chat_history 不会被导入。

编辑 config/broadcast.json：approved.books 填相对 media/books 的路径，music/videos 分别填相对各自媒体目录的路径。只添加已确认内容和公开直播使用权限的文件。初始白名单为空。blocked_phrases 可填自定义禁止播出的短语，每次检查重新读取。此检查只是规则过滤，不是完善的语义审核，不能保证不违规。

直播模式仅允许 local_bookshelf/local_stage 工具；关闭临时书籍导入、读者直接语音接口和本地媒体文件选择。预生成 AudioOutput 暂不播出，以免绕过文本语音检查。

网页右上角提供 AI 身份提示与紧急停止，停止该网页的后续音频、字幕和工具事件并发出中断。文件级停止：创建 cache/broadcast.stop，将阻止后续文本输出、工具和媒体访问，网页每秒检查并停止媒体。已送入浏览器的音频仍应配合 OBS 静音/待机快捷键；这不是 OBS 输出总闸。恢复前移除停止文件并刷新网页。

当前交付为直播基础边界；语义审核、弹幕公平队列、OBS 联动、节目状态持久化和实际播放回执尚未完成。不要把原型按无人值守直播部署。
