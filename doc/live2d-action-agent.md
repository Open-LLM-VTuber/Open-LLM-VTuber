# Live2D 动作代理

重启服务并刷新浏览器页面后生效。代理复用主对话模型，不额外请求一次大模型。
读取当前角色 .model3.json 的 Motions，排除待机组和不存在的文件；将实际可用动作加入角色提示词。
主模型使用 [action:0] 这样的标签选择动作。后端验证编号并清除标签，动作随语音消息发送。
每次回复最多两次且不连续触发；浏览器至少间隔 4 秒，使用普通优先级，避免强行打断已有动作。

## 配置角色

在 model_dict.json 对应角色对象内添加可选字段：

```json
"actionAgent": {
  "enabled": true,
  "traits": "活泼但不夸张，讲解时动作克制",
  "motionDescriptions": {
    ":0": "预览确认后填写第一个动作的实际含义",
    ":1": "预览确认后填写第二个动作的实际含义"
  }
}
```

键为“动作组:组内索引”。mao_pro 的非待机动作组为空字符串，键为 :0 到 :5。
其他模型例如 Tap 组第一个动作，键为 Tap:0。
不配置描述的动作只暴露文件名，提示词要求仅在用户要求展示动作时选择，不猜测动作语义。
可对智能体说“展示一下你的第一个动作”，逐个观察后填写准确描述。
修改配置后重启服务；enabled=false 禁用动作代理，原有表情功能继续工作。

## 客户端范围

本项目 HTTP 首页自动加载 live2d_actions.js 适配器，对现有浏览器前端增加语音同步动作。
不修改 frontend 子模块的编译文件。独立 Electron 客户端如未加载服务器首页，需自行加载此适配器。
客户端依赖当前前端的 getLAppAdapter / getModel / startMotion 接口；升级前端后需复核。
当前不生成新动画，不控制模型未提供的骨骼参数。
